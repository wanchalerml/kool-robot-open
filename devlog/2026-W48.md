# สัปดาห์ 48 · 23–29 พ.ย. 2569

**ลองอะไร**
- เปลี่ยนสัดส่วนอ้างอิงเป็น K-Bot 1.40 ม. · ตั้งเป้ารุ่นแรกเป็นหุ่นโชว์ไม่มีมอเตอร์ข้อ
- CAD เท้าล้อ: ล้อขับนอกเท้า ±22 ซม. · ล้อหมุนตาม · สปริงแม่พิมพ์ 2 ชุด/เท้า · สลักล็อก · ซ็อกเก็ตขาถอดเร็ว
- ทับภาพแนวคิดกับโครง K-Bot และลองแบบผอม "มอเตอร์โผล่ ครอบเฉพาะลิงก์"

**ผ่าน**

- แบบผอมลดเงาขา/เอวได้ 35–47%

**พัง / ต้องแก้**
- นับฐานล้อถึงแกนหมุนล้อหมุนตาม → ตอนถอยมุมล้มหลังเหลือ 14.8° → เปลี่ยนเป็นนับถึงจุดแตะพื้นตอนแย่สุด
- ย้ายแบตขึ้นอก/เป้หลังทำให้ล้มง่ายขึ้น (13.4°) → รุ่นโชว์เก็บแบตไว้ต่ำ
- ไหล่ลดได้น้อย เพราะขนาดมอเตอร์ RS03

**ต่อไป**
- เท้าล้อทรงแคบ · มอเตอร์หลอกขนาด RobStride + ข้อ Hirth · เปลือกลิงก์

## 25–26 พ.ย. (ฉบับร่าง · ยังไม่ทดสอบจริง)

**ตัดสินแล้ว**
- **แผนรุ่นใหม่:** V1 = หุ่นโชว์สวยตามภาพต้นแบบ (ไม่ยึดสัดส่วน K-Bot) · V2 = แขนขยับได้ · V3 = ทำใหม่ตาม K-Bot
- **เปลือกจากโมเดล AI:** สร้างโมเดล 3 มิติทั้งตัวจากภาพแนวคิด 3 มุม แล้วตัดเปลือกพิมพ์จากผิวนั้นตรง ๆ (ผนัง 2.4 มม. ด้วย SDF) · จุดข้อใช้ตามโมเดล · ขาตรง
- **หัว:** หน้าดำเต็มหน้า · ตา = จอ 1.9" ×2 หลังฝาหน้า · จอ 3.5" โผล่หลังหัว · ฝาหน้าพิมพ์ PC Clear Black
- **จออก 8"** (แทน 7") ในกล่องบาง **ก้ม-เงยได้** (+25° / −10°) ด้วยข้อฝืด M6 + แหวนจาน + ยางกันชน TPU ×4 · Pi 5 ย้ายเข้าอก
- **ทุกข้อแขน/คอ = ข้อฝืด** (แผ่นฝืด + M8 + แหวนจาน) จับดัดท่าได้เลย ไม่ต้องขันลูกบิด
- **เท้าล้อ V1:** 2 ล้อขับ hub 4.5"/เท้า (ขับ 4 ล้อ เผื่องานกลางแจ้ง) · คานกระดกทรงกระดูก ±10° · ข้อเท้ายุบ 25 มม. ด้วยสปริงรอบแกนนำ + บุชเชิงเส้น · ปลอก Al ใส่แบริ่ง + แผ่นรองเพลาเหล็กตัว D · ตัวขับล้อย้ายเข้าท้อง
- **แบต:** Li-ion NMC 21700 8S2P ต่อขา ในหน้าแข้งรอบท่อขา (8S เพราะตัวขับล้อรับ 24–48 V)
- **หูหิ้วเอว 2 ข้าง + ห่วง M8** สำหรับยก 2 คน (กำลังออกแบบ)
- **กติกาวัสดุ:** แข็งตึง+ใกล้มอเตอร์ร้อน = PPA-CF · โดนกระแทก = PAHT-CF · ที่เหลือ PETG-CF / PLA
- **ความปลอดภัย/นำทาง** (จากการศึกษาหุ่นส่งอาหาร): ToF ×4 ปลายเท้า · ไมโครสวิตช์กันชน ×8 ตัดไฟล้อ · IMU + encoder ล้อ → ROS 2 / Nav2 · จอยบลูทูธให้คนขับแทน · จำกัด ≤ 0.5 ม./วิ ใกล้คน · มีแผนกลับแท่นชาร์จเอง (กำลังเลือกวิธี)
- **KOOL Mini** (หุ่นเล็ก ขา 6 ข้อ ฐาน Zeroth): เกราะเหลี่ยม + หัวไข่หน้ากากดำ · ซิมฝึกเดินรอบ 4 ยืนได้ ~34 วิ/ตอน · เลือกเซอร์โว STS3250 ×16 + STS3215 ×4

**ผ่าน (บนคอมพิวเตอร์)**
- เท้า V1: เช็กชนทุกท่า (กระดก ±10° × ยุบ 0/25 มม.) ผ่าน · คำนวณรับน้ำหนักแนวดิ่ง ~580 กก. รวม 2 เท้า · ด้านข้างอ่อนสุด ~25 กก./ข้าง (ห้ามยก/ลากจากเท้าทางข้าง)
- กล่องจอ 8": มุมก้ม-เงยไม่ชนอก

**ลองแล้วไม่เวิร์ก / ถูกตัด**
- ข้อ Hirth + ลูกบิด → เปลี่ยนเป็นข้อฝืด (ปรับท่าง่ายกว่า ไม่ต้องขัน)
- เท้าล้อ v1/v1.1 (ล้อขับ 1 + ล้อหมุนตาม, แผ่น Al) → แทนด้วยเท้า 2 ล้อขับ + สปริง
- ตัวขับล้อในเท้า → ใหญ่เกินทรงเท้าในภาพ ย้ายเข้าท้อง
- โช้ค RC ในข้อเท้า → สั้นเกินช่อง เปลี่ยนเป็นสปริงรอบแกน
- แบต LiFePO4 7S → ตัดไฟที่ ~40% ของตัวขับล้อ เปลี่ยนเป็น 8S NMC
- จอตา CYD 2.8" ตัวเดียว / หน้ากากแถบคาดหน้า → เปลี่ยนเป็นหน้าดำเต็มหน้า + จอ 1.9" ×2
- จอ 10.1" ที่อก → ล้นขอบอก เลือก 8"
