## ตั้งค่าทั่วไป
- ชั้น 0.2 มม. (เปลือกผิวโค้งใช้ 0.12–0.16 มม.) · ผนัง: ชิ้นทั่วไป 3 เส้น · ชิ้นรับแรง ≥ 5 เส้น (2.0 มม.)
- Infill: เปลือก 10–15% · ปลอกยึด/ฮับข้อฝืด 40–60% gyroid · คานเท้า ผนัง 6 + 60%
- เตียงพิมพ์ 256 มม. — เปลือกใหญ่ (ลำตัว ต้นขา) แบ่งชิ้นตามเตียง
- เผื่อรูตาม `cad/params.py`: สวมลื่น +0.2 · สวมแน่น +0.1 · รูแนวนอนเพิ่ม +0.1 มม.

### ตั้งใน Bambu Studio (X2D) · How to set it in Bambu Studio
ไฟล์ `.3mf` ใน `hardware/cad/out/print_v1/` ทำจาก PrusaSlicer → Studio โหลดได้แค่รูปทรง **ค่าพิมพ์ไม่ติดมา ต้องตั้งเองทุกจาน** (ค่าเริ่มต้น "0.20mm Standard" = ผนัง 2 · infill 15% อ่อนกว่าแบบมาก)
1. Process → Strength: **Wall loops** · **Bottom shell layers** 4 · **Sparse infill density** · **Sparse infill pattern** = Gyroid ตามตารางบน
2. Support: Enable · Type **tree(auto)** · **On build plate only** ✓
3. Others: Brim type **Outer brim only** 5 มม. สำหรับชิ้นสูง (สูง ≥3× ฐาน) · ชิ้นยาว >150 มม. · TPU
4. X2D: PETG-CF / PAHT-CF ใช้หัว **hardened steel** · เส้นแห้งตามตารางบน · แผ่น Textured PEI · เตียง 70 °C (PETG-CF)
5. ก่อน slice: เช็ก**ส่วนที่ลอยเหนือเตียง 0.05–2 มม.** (หน้าตัดที่ z 0.1 / 0.3 / 0.5 ต้องเท่ากัน) — ถ้าลอยจะเริ่มพิมพ์กลางอากาศ ซัพพอร์ตลงไม่ได้
6. หลัง slice: ชั้นแรกต้องเห็นชิ้นครบ · ไม่มีคำเตือน "floating cantilever" / "overhang regions could not get support" · เทียบน้ำหนักกับที่คาด

**ปลอกแกน (spine collar) — แก้ 27 พ.ย.:** แขนปลอกอยู่ระดับรูเปลือก ไม่ตรงก้นวงปลอก → วางพิมพ์แล้วใต้แขนลอย 0.1–1.5 มม. · ไฟล์จาน PETG-CF 1–4 ใน repo เติมแผ่นรองใต้แขนลงถึงเตียงแล้ว (หนาเพิ่ม ≤1.5 มม. · เช็กไม่ชนเปลือก) · Bambu Studio ประมาณจาน 1 ค่า struct = 94 ก. · 3 ชม. 51 นาที (กำลังพิมพ์ · ยังไม่ทดสอบสวมท่อจริง)

## ซัพพอร์ต
| ชิ้น | วางพิมพ์ | ซัพพอร์ต |
|---|---|---|
| เปลือกนอก | ด้านในลงเตียง | tree support เฉพาะใต้ขอบ · ผิวนอกไม่แตะซัพพอร์ต |
| กรอบจอ | หน้าจอคว่ำลง | ไม่ต้อง |
| คานเท้า | นอนราบ | ไม่ต้อง |
| ปลอกยึดท่อ / ปลอกแกน | รูท่อแนวตั้ง (วงปลอกลงเตียง) | tree บนแผ่น (ใต้ปลายแขน/boss) · ไฟล์ต้องไม่มีแขนลอย |
| ฝาปลายมอเตอร์ | ด้านเรียบลงเตียง | ไม่ต้อง |

**ห้ามพิมพ์ (ใช้โลหะ):** ท่อขาและแกนลำตัว · แผ่นสะโพก · ปลอกใส่แบริ่งเท้า · แผ่นรองเพลาล้อ · แกน/เพลา
