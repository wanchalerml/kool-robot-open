# sim/ — calculations (Apache-2.0)

MuJoCo / numpy scripts for the show robot: tip-over angles, stance, reach, terrain, wheel-foot tilt.
Uses the unmodified K-Bot model in `third_party/kscale/` (MIT).

```bash
pip install mujoco numpy matplotlib
python3 sim/kbot/show_v1_tip.py
```
